**Role:** Simulation & Algorithm Engineer
**Tech Stack:** InfoVista Planet, 3D Spatial Data Processing, Python, Statistical Modeling

### System Architecture & Objective

Engineered a comprehensive software simulation pipeline for an SKT (SK Telecom) project to evaluate macroscopic Key Performance Indicators (KPIs). The core objective was to utilize commercial RF simulation platforms to build a high-fidelity "Digital Twin" of the target environment, enabling zero-risk algorithm validation and theoretical performance bound testing prior to any physical deployment.

### Core Technical Contributions

- **Virtual Environment Reconstruction:** Leveraged the **Planet** simulation software to ingest massive amounts of spatial, elevation, and topological data, successfully rendering a highly accurate 3D Digital Twin of the testing environment.
- **RF Propagation Modeling:** Configured and executed complex ray-tracing and propagation models within the digital twin to simulate signal attenuation, multi-path fading, and interference patterns across the virtual network grid.
- **KPI Predictive Analysis:** Developed Python scripts to parse the large-scale simulation logs generated by Planet. Conducted extensive data analytics to map out the theoretical bounds for critical metrics such as Signal-to-Noise Ratio (SNR), throughput, and spectral efficiency.
- **Data-Driven Strategy:** Translated millions of raw simulated data points into comprehensive statistical reports, providing pure software-driven insights into the performance limits of the proposed network architecture.

*Note: My responsibilities were strictly limited to software-based simulation, mathematical modeling, and data analytics. No physical infrastructure deployment or hardware configuration was involved.*
